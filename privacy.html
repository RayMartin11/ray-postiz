Privacy policy

Last updated: 30 October 2026

Ray Postiz is a private scheduling tool run by Nicholas Ray Martin ("Ray") for his own social media accounts only. It has no other users.

What data it uses

When Ray connects his YouTube account, the app receives an access token from Google that lets it upload videos, set their titles, descriptions and privacy status, and read basic channel information and video statistics for Ray's own channel. It does not access any other person's data.

How it is used

The data is used only to publish videos Ray has approved and to show him how his own videos perform. It is not sold, shared with third parties, used for advertising, or used to train AI models.

Where it is stored

Tokens and video files are stored on Ray's own computer in a self-hosted Postiz database. Nothing is stored on third-party servers other than the platforms Ray posts to.

Google API Services

This app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Ray Postiz's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Disconnecting the channel in Postiz deletes the stored token. To ask for any stored data to be deleted, email raymartin.glvent@gmail.com; it is deleted within 7 days.
